Contact TikVideo

TikVideo currently uses its public project repository as the published contact channel. This avoids presenting an invented or unmonitored email address.

Service, privacy or copyright request

Open a request through the project's GitHub repository and include only the information needed to explain the issue. Do not post passwords, payment details, private identity documents, or other sensitive information in a public issue.

Open the TikVideo GitHub repository

Security

For a security issue, avoid publishing exploit details in a public issue when they could put users at risk. Use the repository's available private reporting options when available.

التواصل مع TikVideo

يستخدم TikVideo حاليًا مستودع المشروع العام على GitHub كقناة التواصل المنشورة. والهدف هو عدم عرض عنوان بريد إلكتروني غير حقيقي أو غير مراقب.

طلبات الخدمة أو الخصوصية أو حقوق النشر

يمكن فتح طلب من خلال مستودع GitHub للمشروع مع تضمين المعلومات اللازمة فقط لشرح المشكلة. لا تنشر كلمات المرور أو بيانات الدفع أو وثائق الهوية الخاصة أو أي معلومات حساسة في Issue عامة.
