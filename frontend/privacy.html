Privacy Policy

This page describes the current behavior of the TikVideo website. It is not legal advice and should be reviewed for the laws that apply to the operator and users.

Accounts

TikVideo currently has no user registration, login, profile, or account database.

Information submitted to the service

When you submit a supported TikTok URL, the browser sends that URL to the TikVideo service so it can attempt to retrieve available media information. Short-lived authorization tokens are generated for API requests. The service does not provide a user-facing history or saved download library.

Browser storage

The site uses local browser storage to remember the selected interface language. The current frontend does not use a login cookie for user accounts.

Technical data

The hosting provider and network infrastructure may process normal technical information such as IP addresses, request timestamps, HTTP information, error logs, and security logs as part of operating and protecting the service. Retention and processing of such infrastructure logs depend on the hosting provider and applicable law.

Third-party services

Video retrieval may contact external media services and the source platform. Those services may process requests under their own terms and privacy policies. TikVideo does not control their independent data practices.

Children

The service is not designed to collect personal information from children. Users should comply with applicable age requirements and laws.

Changes

This policy may be updated when the service architecture or legal requirements change. The current version is published on this page.
